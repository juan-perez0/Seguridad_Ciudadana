Dashboard de Seguridad Ciudadana en Cundinamarca

Modelo multidimensional integrado en una solución web con Flask y Power BI

Visualización analítica

Este dashboard permite analizar indicadores de seguridad ciudadana por municipio, año, categoría delictiva e indicador, a partir del modelo multidimensional construido.
