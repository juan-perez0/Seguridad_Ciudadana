Análisis de Minería de Datos

Contexto del Problema

El análisis se centra en el estudio de la seguridad ciudadana mediante el procesamiento de datos de delitos registrados en diferentes municipios y años. El objetivo es identificar patrones, tendencias y comportamientos relevantes para la toma de decisiones.

Modelo Multidimensional

Hechos: Número de casos reportados (DATO_NUMERICO)

Dimensiones:

  • Municipio
  • Año
  • Tipo de delito

Se implementó un modelo tipo estrella que permite analizar los datos desde múltiples perspectivas.

Proceso ETL

  • Limpieza de datos
  • Conversión de tipos numéricos
  • Eliminación de valores nulos
  • Transformación de variables
  • Generación de datasets analíticos

Análisis Realizado

  • Identificación de municipios con mayor número de casos
  • Análisis de evolución de delitos por año
  • Comparación entre regiones

Análisis con PySpark

Se utilizó PySpark para procesar grandes volúmenes de datos de forma distribuida, permitiendo mejorar el rendimiento y la eficiencia del análisis.

  • Procesamiento distribuido
  • Agrupaciones por municipio y año
  • Cálculo de indicadores
  • Generación de datasets optimizados

Machine Learning (Clustering)

Se aplicó el algoritmo KMeans para segmentar municipios según su nivel de incidencia delictiva.

  • Cluster 0 → Baja incidencia
  • Cluster 1 → Media incidencia
  • Cluster 2 → Alta incidencia
