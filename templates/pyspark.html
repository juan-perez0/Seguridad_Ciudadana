Objetivo del análisis

Esta sección presenta el análisis avanzado realizado con PySpark sobre datos de seguridad ciudadana en Cundinamarca. Se utilizó un dataset ampliado para simular un escenario de gran volumen y aplicar procesamiento distribuido, consultas analíticas y Machine Learning con MLlib.

¿Qué se hizo con PySpark?

El archivo base utilizado fue seguridad_clean.csv. Este dataset fue cargado como Spark DataFrame, limpiado y transformado para generar consultas distribuidas. Para simular un volumen mayor de datos se aplicó un factor de ampliación, por lo que los totales procesados representan datos ampliados para prueba de rendimiento.

1. Carga

Lectura del dataset limpio mediante Spark DataFrame.

2. Transformación

Conversión de DATO_NUMERICO, eliminación de nulos y preparación de variables.

3. Consultas

Agrupaciones por municipio, año y cálculo de promedios.

4. MLlib

Segmentación de municipios mediante KMeans.

Conclusiones del conocimiento profundo

  • PySpark permitió transformar el análisis tradicional en un proceso escalable basado en procesamiento distribuido.
  • El dataset fue ampliado para simular un volumen mayor de información y evaluar el comportamiento del procesamiento.
  • Las agrupaciones distribuidas permitieron identificar municipios y años con mayor concentración de registros.
  • El uso de MLlib permitió segmentar municipios mediante KMeans y generar perfiles de incidencia.
  • La comparación de tiempos evidenció que Spark tiene un costo de arranque mayor, pero ofrece ventajas para escenarios de mayor volumen y paralelismo.
  • El conocimiento profundo complementa los niveles evidente, multidimensional y oculto, fortaleciendo el ciclo completo de análisis del proyecto.
